# YouTube Trending Video Analytics

## Objective
Analyze YouTube trending videos to identify patterns in views,
categories, sentiment, and trending behavior.

## Tools
- Python
- Pandas
- Matplotlib
- SQL
- Tableau

## Analysis
- Data cleaning
- Exploratory data analysis
- Category analysis
- Sentiment analysis
- Time-series analysis
- SQL analysis
- Region-wise comparison

## Dashboard
Tableau dashboard showing popular categories, sentiment,
views over time, and regional comparison.
